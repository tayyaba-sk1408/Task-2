# Task-2Personal Profile Webpage

A simple personal profile webpage created using HTML5 and CSS3 as part of my internship task. The webpage presents personal information in a clean and responsive layout.

Project Description

This project is a single-page personal introduction website that contains basic information about me, including my introduction, skills, hobbies, and contact details. The main purpose of this project was to practice HTML structure and CSS styling.

Features
Personal name and introduction
Profile image
About Me section
Skills section
Hobbies section
Contact information
Responsive layout
Simple and clean design
CSS-based spacing, colors, and typography
Technologies Used
HTML5
CSS3
Project Structure
Personal_Webpage/
│
├── index.html
├── style.css
└── profile.jpg
How to Run
Download or clone the project.
Open the project folder.
Make sure index.html, style.css, and profile.jpg are in the same folder.
Open index.html in any web browser.
